# Matrix Code v1.1.0

Prebuilt downloads are hosted at <https://julimbob.com/matrixcode/releases/v1.1.0/>.
The download table at the top of the main README links to each package and the
SHA-256 checksum file.

- macOS: Developer ID signed, notarized, stapled Apple Silicon DMG containing both Matrix Code.app and Matrix Code.saver; macOS 13 or newer.
- Ubuntu: native amd64 and arm64 Debian packages for Ubuntu 24.04 or newer, including the app and X11 XScreenSaver integration.
- Windows: x64 and ARM64 native app and screen saver, available as MSI installers and portable ZIPs; Windows 10 version 2004 or newer. These Windows builds are unsigned.
- Wallpaper Engine: self-contained ZIP generated from the browser implementation. Extract it and import index.html using Create Wallpaper.

This release adds occasion greetings, settings that follow the active theme,
and clear labels for calendar colour overrides. It also improves the Linux
XScreenSaver settings launcher, browser project links, search and share
previews, and the project marketing video.

The browser remains the visual and behavioural source of truth for the native
implementations. Automated native tests and software render captures accompany
the Windows and Ubuntu builds. Mixed-DPI/mixed-refresh displays, GPU/driver
combinations, monitor hot-plug, and suspend/resume still need the hardware
validation described in each native README.
