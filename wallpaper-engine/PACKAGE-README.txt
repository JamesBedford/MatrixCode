MatrixCode for Wallpaper Engine
===============================

Import index.html with Wallpaper Engine's Create Wallpaper command.
Use the Wallpaper Engine property pane to configure the rain, intro,
messages, countdown moments and image reveals.

For continuous rain across multiple displays, configure Wallpaper Engine
to span one wallpaper across the displays. Separate per-monitor instances
are independent because Wallpaper Engine does not expose their virtual offsets.

Image folders are sorted deterministically and limited to 64 valid images.
This package is self-contained and does not require a network connection.
MatrixCode and bundled third-party license notices are in LICENSES.txt.
